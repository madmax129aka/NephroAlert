Abstract

Chronic Kidney Disease (CKD) affects approximately 17% of India's adult population, with diabetic nephropathy accounting for nearly 40% of all CKD cases. Despite routine blood test collection at Primary Health Centres (PHCs), no existing clinical decision support tool analyses longitudinal biomarker trajectories to predict CKD progression before irreversible damage occurs. This project proposes NephroAlert — a lightweight, web-based AI system that analyses multi-visit patterns of serum creatinine, eGFR, HbA1c, blood urea, urine ACR, and blood pressure to generate a quantified CKD progression risk score. Unlike threshold-based single-visit evaluation, NephroAlert detects dangerous declining trajectories 4–6 months earlier. Validated on de-identified retrospective PHC data from Tamil Nadu, this tool aims to enable timely nephrology referrals, reduce preventable kidney failure, and support rural healthcare workers with AI-assisted clinical decisions.

Core Algorithms — The Mathematical Foundation

Algorithm 1 — CKD-EPI 2021 Real-Time eGFR Calculation

For Scr / κ < 1:

eGFR = 142 × (Scr/κ)α × (0.9938)Age

For Scr / κ ≥ 1:

eGFR = 142 × (Scr/κ)−1.200 × (0.9938)Age

κ = 0.7 (Female) | 0.9 (Male)  ·  α = −0.241 (Female) | −0.302 (Male)  ·  Female multiplier ×1.012

Algorithm 2 — Linear Regression Slope (Trajectory Detection)

slope = (n·ΣXY − ΣX·ΣY) / (n·ΣX² − (ΣX)²)

X = visit number, Y = biomarker value

Creatinine 0.9→1.1→1.4→1.7→2.1  ·  slope +0.30/visit  ·  RAPIDLY RISING 🔴
Creatinine 0.8→0.8→0.9→0.8→0.8  ·  slope +0.01/visit  ·  STABLE 🟢

Conclusion & References

Conclusion

✓NephroAlert addresses a genuine clinical gap: no existing tool analyses longitudinal biomarker trajectories for CKD prediction at PHC level in Tamil Nadu.
✓The system requires zero additional hardware, integrates with existing PHC workflows, and outputs results in Tamil — making it truly deployable in rural healthcare settings.
✓By detecting CKD 4–6 months earlier than threshold-based single-visit evaluation, NephroAlert can prevent irreversible nephron loss in thousands of patients.
✓The pilot dataset collected from Tamil Nadu PHCs represents an original research contribution with no existing equivalent in published literature.
✓This project demonstrates a scalable, evidence-based model for AI-assisted chronic disease monitoring that can be extended across Tamil Nadu and India.

With the generous support of ACS-AMRI seed funding, NephroAlert will progress from prototype to validated clinical decision support tool — directly saving lives by catching kidney disease before it becomes kidney failure.
